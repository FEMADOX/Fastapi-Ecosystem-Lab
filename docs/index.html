Quick Start

Get the full stack running locally in minutes.

1

Clone the repository & install dependencies

git clone https://github.com/FEMADOX/Fastapi-Ecosystem-Lab.git
cd Fastapi-Ecosystem-Lab
uv sync
2

Configure environment variables

cp learn_fastapi/.env.example learn_fastapi/.env
# Edit learn_fastapi/.env with your settings
3

Start PostgreSQL with Docker

cd learn_fastapi
docker compose up -d
4

Run database migrations

cd learn_fastapi
uv run alembic upgrade head
5

Start the FastAPI server

# From the repository root:
uv run run-api-server
# API available at http://localhost:8000/api/v1
# Interactive docs at http://localhost:8000/api/docs
6

Launch the Streamlit frontend

# In a second terminal, from the repository root:
uv run streamlit run learn_streamlit/src/app.py
# UI available at http://localhost:8501

☁️ Deploy Streamlit to the cloud

The Streamlit frontend can be hosted for free on Streamlit Community Cloud. Point it at learn_streamlit/src/app.py in this repository, and set the FastAPI backend URL via the FASTAPI_BASE_URL environment variable in Streamlit Cloud's secrets manager.
